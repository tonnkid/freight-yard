A round-based tactical FPS in the Counter-Strike mould, built on three.js 0.187.0 and running as plain static ES modules in a desktop browser. Two five-player teams contest a freight yard across short rounds won by wiping the other side or by planting and holding the bomb. Between rounds you spend the money you earned on a rifle, kevlar or utility; accuracy and positioning beat raw speed, and the bots push the lane on their own schedule rather than waiting to be shot.

The map, art, sounds and weapon names are the game's own. Nothing is copied from an existing commercial title.

## Run it

```sh
node serve.ts
```

Open http://localhost:8080 in desktop Chrome. The game makes no network request after the page loads.
